🧮 Equation Solver

A simple and powerful tool to solve algebraic equations, including linear, quadratic, and systems of equations. Designed for students, teachers, and developers who need quick, reliable solutions.

✨ Features

    ✅ Solve linear equations (e.g. 2x + 3 = 7)

    ✅ Solve quadratic equations (e.g. x² - 4x + 4 = 0)

    ✅ Support for systems of equations

    ✅ Step-by-step output

🚀 Getting Started
Prerequisites

    Python 3.7+

Installation

Clone the repository:

    git clone https://github.com/pryogendra/Equation-Solver.git
    cd Equation-Solver
